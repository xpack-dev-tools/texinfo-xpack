# The xPack GNU texinfo

A standalone, cross-platform (macOS, GNU/Linux) binary
distribution of GNU texinfo,
intended for reproducible builds.

## Project documentation

For information on how to install and use this project, please refer to the
[project website](https://xpack-dev-tools.github.io/texinfo-xpack/).

## Project source

The source code of the current release is available on
[GitHub tag v7.0.3-1.1 tree](https://github.com/xpack-dev-tools/texinfo-xpack/tree/v7.0.3-1.1).
